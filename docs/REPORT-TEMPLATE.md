# 收工汇报模板

> 每个任务结束时填写。内容必须能让未参与实现的人快速判断结果和下一步。

```text
Done：本次完成什么（带任务 ID 与证据）
Doing：正在进行、尚未完成的部分
Blocked：阻塞项及原因
Next：下一步计划
需拍板：需要决策的事项；没有写“无”
本次新术语：术语 + 一句人话解释；没有写“无”
```
