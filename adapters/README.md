# 技术栈适配器

适配器是把通用流程接到具体技术栈的薄层。核心流程不应依赖某个语言、框架、包管理器或 CI 平台；项目只需补充“如何执行检查、如何预览、如何保存证据”。

## 适配器必须回答的问题

1. 如何安装或准备依赖？
2. 如何执行 lint、类型检查、单元测试和构建？
3. 如何执行端到端或人工冒烟？
4. 如何启动本地预览？
5. 证据保存在哪里？
6. 哪些命令可能修改文件或产生外部副作用？
7. 如何在失败后清理或回滚？

## 推荐文件格式

每种技术栈建立一个说明文件，例如：

```text
adapters/
├─ README.md
├─ typescript.md
├─ python.md
└─ generic.md
```

## 使用规则

- 具体命令写入 `workflow.config.yml`，不要散落在多个文档中。
- 命令必须可复制执行。
- 缺少某种检查时，明确写“未配置”和原因。
- 适配器不能改变任务状态机和完成定义。
